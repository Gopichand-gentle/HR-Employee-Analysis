# HR Employee Analysis Dashboard

## Project Overview
The **HR Employee Analysis** project analyzes employee data to identify workforce trends, employee attrition, salary patterns, job satisfaction, tenure, workload, and departmental performance.
An interactive dashboard was developed using **Power BI** to transform raw HR data into meaningful business insights and support data-driven HR decision-making.

##  Objectives
* Analyze employee attrition and retention patterns
* Identify departments with higher/lower attrition
* Evaluate salary distribution across departments
* Analyze employee satisfaction and tenure
* Understand workload and project distribution
* Track key HR performance indicators
* Present insights through an interactive dashboard

## Tools & Technologies
* **Power BI** – Data visualization and dashboard development
* **DAX** – KPI and calculated measure creation
* **Power Query** – Data cleaning and transformation
* **Excel/CSV** – Data source and preprocessing

## Key KPIs

* Total Employees
* Employees Left
* Employees Stayed
* Attrition Rate
* Average Satisfaction
* Average Salary
* Average Tenure
* Average Projects

## Dashboard Analysis

The dashboard provides insights into:

* **Employee Attrition Analysis**
* **Attrition by Department**
* **Attrition by Tenure**
* **Salary Analysis**
* **Employee Satisfaction**
* **Projects and Workload**
* **Department-wise Performance**
* **Workforce Distribution**

## Key Insights

The analysis helps HR teams understand employee behavior, identify potential retention challenges, compare departmental performance, and evaluate factors associated with employee attrition.

## Business Value

This project demonstrates how data analytics can support **HR decision-making** by converting employee data into actionable insights related to workforce planning, employee retention, compensation, satisfaction, and departmental performance.
